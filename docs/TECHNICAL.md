# Техническое описание

Версия игры: **Big Dig v1.0**, Unity **6000.4.10f1**, Addressables **2.9.1**, Unity Localization.

## Как устроена локализация

В игре шесть таблиц строк:

| Таблица | Строк |
|---|---:|
| Dialogue | 445 |
| UI | 156 |
| MapSites | 16 |
| Artifacts | 98 |
| ArtifactDescriptions | 78 |
| Upgrades | 128 |
| **Итого** | **921** |

Оригинальный русский бандл существует, но таблицы в нём пустые: игра падала на fallback `en`. Поэтому перевод не добавляет новый язык, а заполняет уже существующий `ru`.

## Что заменяется

### 1. `localization-string-tables-russian(ru)_assets_all.bundle`

В бандле шесть `MonoBehaviour` с именами `Dialogue_ru`, `UI_ru`, `MapSites_ru`, `Artifacts_ru`, `ArtifactDescriptions_ru`, `Upgrades_ru`.

Для каждой таблицы:

- берётся структура английской таблицы (`*_en`): `m_Id`, порядок строк, `m_Metadata`;
- `m_Localized` подставляется из `translation/ru/*.json`;
- `m_Metadata` и `references` копируются из английской таблицы, чтобы не потерять SmartFormat-теги;
- пустые строки остаются пустыми;
- RU-only строки, которых нет в EN, сохраняются.

Размер: **107 187 байт**.

### 2. `localization-locales_assets_all.bundle`

В бандле 12 локалей. У русской меняется только отображаемое имя:

```
m_LocaleName: "Russian (ru)" -> "Русский"
```

Остальные локали не трогаются. Размер: **9 355 байт**.

### 3. `catalog.bin`

Addressables-каталог хранит CRC и размер каждого бандла. После правки бандлов:

- у записи русского бандла строк (offset **13893**) CRC ставится в `0`, размер — `107187`;
- у записи бандла локалей (offset **10431**) CRC ставится в `0`, размер — `9355`;
- `catalog.hash` не меняется: локальная проверка хэша игре не мешает.

CRC обнуляется, потому что содержимое бандла изменилось, а пересчитывать CRC под формат Addressables не нужно: игра принимает `0`.

### 4. `BigDig_Data\level0` … `level12`

В каждом уровне есть список `disabledLocales`:

```
da, fr, pt-BR, ru, es, de
```

Игра скрывает русский из меню, потому что он в этом списке. Заменяем `ru` на `xx`:

```
da, fr, pt-BR, xx, es, de
```

Замена той же длины, поэтому размеры файлов не меняются. Патчатся все 13 уровней. После этого «Русский» появляется в списке языков.

### 5. Сохранение

В `%USERPROFILE%\AppData\LocalLow\BirdGang\BigDig\<SteamID>\<SteamID>_save.json`:

```json
"languageCode": "ru"
```

Прогресс, деньги, артефакты и настройки не меняются. Если сохранения нет, язык выбирается в настройках.

## Шрифты

Шрифты не заменялись. В игре TMP-атласы динамические: глифы кириллицы добавляются в атлас при первом использовании. Исходные шрифты содержат русские буквы, поэтому квадратов нет. Проверено на главном меню, настройках, HUD, техдереве, карте и диалоговом окне.

## Проверка

- Строки: 6 таблиц, 921 строка, readback после сборки — 0 расхождений.
- Теги и плейсхолдеры: структурная сверка с английскими таблицами.
- Локали: все 12 записей на месте, имя русской — «Русский».
- Каталог: размеры в записях совпадают с фактическими размерами бандлов.
- Уровни: в каждом изменено ровно 2 байта (`ru` → `xx`).
- В игре: главное меню, настройки, HUD, техдерево, карта, диалог сброса сохранения.

Полный список файлов и SHA256 — в [../SHA256SUMS.txt](../SHA256SUMS.txt).

## Как пересобрать

Нужен Python 3.10+ и UnityPy 1.25.2. Патчер из `patcher/` для установки этого не требует — ему достаточно готовых файлов из `files/`.

Готовый скрипт: [../tools/rebuild.py](../tools/rebuild.py). Он читает установленную игру, собирает бандлы в `build/` и проверяет readback. Инструкция — [../tools/README.md](../tools/README.md).

Общий порядок:

1. Прочитать английские таблицы из `localization-string-tables-english(en)_assets_all.bundle`.
2. Взять русский бандл, заменить `m_TableData` и `m_Metadata` у шести `*_ru` объектов.
3. Сохранить бандл через `env.file.save()`.
4. В бандле локалей выставить `m_LocaleName = "Русский"`.
5. В `catalog.bin` записать CRC `0` и новые размеры по offsets `13893` и `10431`.
6. В каждом `levelN` заменить байты `02 00 00 00 72 75 00 00` на `02 00 00 00 78 78 00 00`.
7. В сохранении заменить `languageCode` на `ru`.

На текущей версии `tools/rebuild.py` выдаёт байт-в-байт те же 16 файлов, что лежат в `files/`. Это проверено сравнением SHA256.

Offsets и имена бандлов привязаны к версии игры. После обновления Big Dig их нужно проверять заново: структура каталога и уровней может измениться.

## Ограничения

- Steam «Проверить целостность файлов» и обновления игры возвращают оригинальные файлы. Патч нужно применить снова.
- `catalog.hash` остаётся оригинальным. Для текущей версии это нормально; если будущая версия начнёт строго проверять хэш, патч потребует пересчёта.
- Перевод проверен структурно и визуально, но полный сюжет от начала до конца не прогонялся. Опечатки и обрезки строк чинятся точечно.
