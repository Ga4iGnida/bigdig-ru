# Исходники перевода

`ru/*.json` — шесть таблиц, 921 строка:

| Файл | Строк | Что это |
|---|---:|---|
| `Dialogue.json` | 445 | Диалоги, реплики, сюжет |
| `UI.json` | 156 | Меню, настройки, HUD, подсказки |
| `MapSites.json` | 16 | Названия районов на карте |
| `Artifacts.json` | 98 | Названия артефактов |
| `ArtifactDescriptions.json` | 78 | Описания артефактов |
| `Upgrades.json` | 128 | Улучшения и исследования |

Формат:

```json
[
  {
    "id": 378779430912,
    "ru": "Нажмите {glyph.feedback}, чтобы оставить отзыв"
  }
]
```

- `id` — идентификатор строки в игре. Его нельзя менять.
- `ru` — русский текст.
- Файлы в UTF-8.

## Правила

Полный глоссарий и правила — в [TRANSLATION_BRIEF.md](TRANSLATION_BRIEF.md). Главное:

- не менять содержимое угловых тегов: `<dog>`, `<frog>`, `<b>`, `<color=#...>`, `<sprite name=...>` и т.п.;
- не терять плейсхолдеры: `{0}`, `{1}`, `{glyph.feedback}` и т.п.;
- сохранять `\n` и пустые строки;
- не переводить названия брендов: Big Dig, Bird Corp, Feed for Speed, Omelet You Cook;
- «Мэр Пёс», «Мэр Лягушка», «Пумба», «Догополис», «Миддлсвилль», «Сделаем это!», «Пожертвование», «Очки исследований».

## Как это попадает в игру

Текст собирается в Addressables-бандл `localization-string-tables-russian(ru)_assets_all.bundle` и ставится вместе с `catalog.bin` и уровнями. Техническое описание — в [../docs/TECHNICAL.md](../docs/TECHNICAL.md).

Если правите текст для себя: после изменения JSON нужен пересбор бандла. Патчер из `patcher/` только копирует уже готовые файлы и не умеет собирать локализацию. Скрипт сборки — [../tools/rebuild.py](../tools/rebuild.py), инструкция — [../tools/README.md](../tools/README.md).
