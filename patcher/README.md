# Патчер

- `Apply-RU.bat` — установка русского перевода.
- `Restore-RU.bat` — откат к последнему бэкапу.

## Требования

- Windows 10/11.
- PowerShell 5.1 — он уже встроен, ставить ничего не нужно.
- Big Dig закрыт.
- Права на запись в папку игры. Если игра лежит в `Program Files`, запустите батник от имени администратора.

## Что делает Apply-RU.bat

1. Проверяет SHA256 всех файлов в `..\files` — чтобы не поставить битый архив.
2. Ищет игру в библиотеках Steam и на рабочем столе. Если не нашёл — открывает окно выбора папки.
3. Проверяет, что игра не запущена.
4. Делает бэкап в `Desktop\BigDig-RU-Backup\<дата>`.
5. Копирует 16 файлов: два бандла локализации, `catalog.bin` и 13 уровней.
6. Меняет `languageCode` на `ru` во всех найденных сохранениях.

Сохранение не сбрасывается: меняется только код языка. Если сохранения ещё нет, патчер просто пропустит этот шаг — язык можно выбрать в настройках.

## Параметры PowerShell

Если хочется запускать без батника:

```powershell
powershell -ExecutionPolicy Bypass -File .\apply.ps1 -GamePath "D:\Games\Big Dig"
```

| Параметр | Что делает |
|---|---|
| `-GamePath "путь"` | Указать папку с `BigDig.exe` вручную |
| `-SkipSave` | Не трогать сохранение |
| `-NoLaunch` | Не спрашивать про запуск игры |
| `-DryRun` | Показать план, ничего не менять |

`restore.ps1` принимает `-BackupPath`, `-GamePath` и `-DryRun`.

## Если что-то пошло не так

- **«Big Dig сейчас запущен»** — закройте игру и запустите снова.
- **«Нет прав на запись»** — запустите батник от имени администратора.
- **SmartScreen ругается на .bat** — это обычный вызов PowerShell. Исходник лежит рядом в `apply.ps1`, его можно открыть блокнотом.
- **Файлы патча повреждены** — скачайте репозиторий заново, не перетаскивайте файлы по одному.
- **Игра не видит русский** — проверьте, что заменены все 16 файлов, и выберите «Русский» в настройках.

Бэкап можно вернуть вручную: скопируйте содержимое `BigDig-RU-Backup\<дата>` обратно в папку игры. `backup-info.json` внутри хранит путь к игре и список сохранений.
